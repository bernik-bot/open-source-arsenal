# Contributing to Security Arsenal & Knowledge Base

First off, thank you for considering contributing to this repository! It's people like you that make this security arsenal a great tool for the community.

We welcome contributions from everyone. Whether you are adding a new tool, fixing a broken link, or proposing a new category, your help is appreciated.

## 📋 How to Contribute

### 1. Adding a New Tool
We want to keep this list high-quality and relevant. If you have a tool you'd like to add, please follow these guidelines:

* **Relevance:** The tool must be relevant to security, penetration testing, cloud assessments, or reconnaissance.
* **Open Source Preferred:** We prioritize open-source tools, but exceptional commercial tools with free tiers are also welcome.
* **Check for Duplicates:** Please search the repository to ensure the tool isn't already listed.
* **Category:** Add the tool to the most appropriate section (e.g., *Enumeration*, *Cloud Security*, *Container Security*).

### 2. Formatting Your Contribution
To maintain consistency, please use the following format for table entries:

`| **Tool Name** | Brief description of what the tool does (max 100 chars). | [Link](URL) |`

**Example:**
`| **Amass** | In-depth attack surface mapping and asset discovery. | [Link](https://github.com/OWASP/Amass) |`

### 3. Reporting Broken Links
If you find a link that no longer works:
* Please check if the tool has moved to a new repository.
* If the tool is deprecated or dead, please open an Issue or a Pull Request to remove it.

## 🚀 Submitting a Pull Request (PR)

1.  **Fork** this repository to your own GitHub account.
2.  **Clone** your fork to your local machine.
3.  Create a new **branch** for your changes:
    ```bash
    git checkout -b add-tool-name
    ```
4.  **Edit** the `README.md` file with your additions or fixes.
5.  **Commit** your changes with a clear message:
    ```bash
    git commit -m "Add ToolName to Enumeration section"
    ```
6.  **Push** to your branch:
    ```bash
    git push origin add-tool-name
    ```
7.  Open a **Pull Request** against the `main` branch of this repository.

## 📝 Style Guide

* **Alphabetical Order:** Whenever possible, keep lists and tables sorted alphabetically by tool name within their sections.
* **Clean Descriptions:** Keep descriptions concise and objective. Avoid marketing buzzwords like "best," "cutting-edge," or "revolutionary."
* **Valid Links:** Ensure all links point directly to the tool's official repository or homepage.

## 🤝 Code of Conduct

By participating in this project, you agree to abide by common courtesy and respect. We are here to learn and share knowledge. Harassment or spamming will not be tolerated.
